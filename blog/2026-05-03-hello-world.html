Hello, world

May 3, 2026 · 2 min read

This is the first post on the new blog section of my site. I built this primarily as a place to write things down — partly so I remember them later, partly so I have to think clearly enough to put them in words.

What I'll write about

  • RL & control: what I'm picking up from the Robot Learning Lab work on distillation columns.
  • Robotics autonomy: ROS2, navigation, and the small-but-painful integration problems that come with Robomaster.
  • Full-stack experiments: things I build on the side — usually small, usually weird.

How this is built

The site is plain HTML/CSS/JS — no framework, no build step. Posts live in blog/ as standalone HTML files, and the listing is driven by a small posts.json. To add a new post, write the HTML and add an entry to the JSON file.
